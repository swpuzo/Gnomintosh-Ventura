# Gnomintosh-Ventura
Gnomintosh Ventura is a macOS 13 Ventura-inspired desktop environment configuration for Linux systems running the GNOME desktop environment.

## Features
* **Ventura UI:** Replicates macOS 13 System Settings side-navigation layouts and rounded window designs.
* **Top Bar & Dock:** Features a clean top menu bar combined with an auto-hide, centered application Dock.
* **Apple Aesthetics:** Includes WhiteSur GTK themes, Monterey/Ventura icon packs, and San Francisco system fonts.
* **Blur Effects:** Powered by Blur my Shell for hardware-accelerated translucent background blurs.

## How to install?
Install the extension from the "Extension" folder, download it. Then download the config from the "dconf" folder. and place it in your home directory. Enter the command: dconf load /org/gnome/shell/extensions/ < Gnomintosh_extensions.conf then download the wallpaper Then open the "logo menu" extension settings and download the logo of your choice from the "logo" folder and place it in the logos then download the icons and theme below in "Credits".
